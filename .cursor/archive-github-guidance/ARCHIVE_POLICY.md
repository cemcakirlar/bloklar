# Archive Policy

This folder keeps guidance from `.github` that is intentionally not active by default in Cursor behavior.

## Archived by Default

- `tailwind-v4-vite.instructions.md`
  - Conflicts with current Tailwind v3 setup in this repository.
- `markdown-content-creation.instructions.md`
  - Contains blog/content workflow constraints that are not general coding rules.
- `polyglot-test-fixer.agent.md`
- `polyglot-test-generator.agent.md`
  - Multi-language and orchestration assumptions exceed this repo's TS/React focus.
- `gh-cli.SKILL.md`
  - Kept as reference only; too broad for default project behavior.
- `webapp-testing-test-helper.js`
  - Utility sample retained for reference, not a default test dependency.

## Activation Rule

Archived docs are opt-in only. They should be applied only when a user explicitly asks for that exact workflow.
