# Webapp Playwright Testing

Use this skill for end-to-end scenario testing and Playwright test authoring.

## Trigger

- User asks to add, improve, or debug browser E2E tests.

## Workflow

1. Model the user journey and critical assertions.
2. Use resilient locators and web-first assertions.
3. Keep tests deterministic; avoid hard sleeps and brittle selectors.
4. Separate setup, action, and assertion clearly.

## Output

- Added/updated test scenarios.
- Notes on flaky points and stabilization decisions.
- Suggested follow-up cases not covered in current scope.
