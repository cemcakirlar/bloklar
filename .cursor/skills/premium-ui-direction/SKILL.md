# Premium UI Direction

Use this skill for visual polish and high-quality UI refinement.

## Trigger

- User requests better visual quality, hierarchy, spacing, or interaction feel.

## Workflow

1. Evaluate hierarchy, spacing, typography, and consistency.
2. Remove visual noise and improve clarity first.
3. Refine interaction feedback and state transitions.
4. Align improvements with existing design language.

## Output

- Prioritized UI improvement list.
- Concrete implementation direction for top issues.
- Tradeoffs between speed, complexity, and visual quality.
