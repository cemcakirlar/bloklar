# Runtime Accessibility Audit

Use this skill for UI accessibility checks and WCAG-oriented remediation guidance.

## Trigger

- User asks for accessibility review, keyboard/focus testing, or aria/semantic validation.

## Workflow

1. Inspect critical UI flows and interactive elements.
2. Check keyboard access, focus order, and visible focus styles.
3. Validate labels, names, roles, and error messaging.
4. Report findings by severity with specific fixes.

## Output

- Critical/important/suggestion findings list.
- Concrete fix direction for each finding.
- Remaining risk or untested surfaces.
