# UI Motion (GSAP/Motion)

Use this skill for animation-heavy UI features using GSAP or Motion.

## Trigger

- User asks for scroll animations, transitions, or interaction motion design.

## Workflow

1. Define motion intent and UX constraints.
2. Choose the simplest animation approach that fits stack and maintainability.
3. Keep motion smooth and accessible (reduced-motion aware).
4. Prevent layout shift and expensive repaint patterns.

## Output

- Motion approach and rationale.
- Performance/accessibility considerations.
- Follow-up tuning suggestions if needed.
