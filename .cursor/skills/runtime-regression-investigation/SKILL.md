# Runtime Regression Investigation

Use this skill to triage behavior regressions quickly and systematically.

## Trigger

- User reports a feature used to work and now fails or behaves differently.

## Workflow

1. Reproduce the issue and capture exact symptoms.
2. Narrow suspect area (UI logic, state, API integration, environment assumptions).
3. Form and test one hypothesis at a time.
4. Produce minimal corrective direction and validation steps.

## Output

- Repro conditions.
- Most likely root cause.
- Recommended fix direction and confidence level.
