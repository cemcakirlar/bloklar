# Runtime Performance Investigation

Use this skill when diagnosing frontend performance regressions.

## Trigger

- User mentions slowness, jank, Core Web Vitals, or render performance issues.

## Workflow

1. Reproduce the slow path and isolate bottlenecks.
2. Identify likely root cause (rendering, bundle, data, animation, blocking tasks).
3. Prioritize fixes by impact and implementation cost.
4. Recommend measurable validation steps.

## Output

- Bottleneck summary.
- Ranked fix list with expected impact.
- Verification plan for LCP/INP/CLS or observed symptoms.
